# Box2D Platformer

![Game Screenshot](screenshot.png)

A feature-rich 2D platformer with physics-based gameplay.

## 🎯 Features
- **Smooth Physics**: Box2D integration for realistic movement
- **Infinite Worlds**: Procedurally generated platforms
- **Visual Effects**: Particle systems and animations
- **Audio**: Background music and sound effects
- **Full UI**: Health bars, score display, pause menu

## 🕹️ Controls
- **Arrow Keys**: Move left/right
- **Space**: Jump/Double jump
- **ESC**: Pause menu
- **F11**: Toggle fullscreen
- **H/J**: Damage/Heal (debug)
- **X**: Spawn explosion

## 📦 Dependencies
- Box2D
- OpenGL
- GLFW
- SDL2_mixer
- FreeType

## 🚀 Quick Start
1. Clone the repository
2. Install dependencies
3. Build with CMake
4. Run the executable
